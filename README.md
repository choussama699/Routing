# Routing Lab - Cisco Packet Tracer

A Cisco Packet Tracer network topology focused on routing concepts and configurations.



## 📋 Description

This project demonstrates routing in a multi-router network using Cisco Packet Tracer.  
It covers fundamental and intermediate routing topics such as:

- Static routing
- Inter-VLAN routing (if applicable)
- Default routes / route summarization
- Connectivity testing and troubleshooting

I have used 3 routers , 2 switches and 2 pcs
